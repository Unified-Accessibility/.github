# Unified Accessibility

We build tools that make the web accessible to everyone, and make accessibility work easier for the teams responsible for it.

## What we're building

### UA Nexus

A web accessibility auditing and project management platform for businesses. UA Nexus helps teams:

- **Audit** websites against WCAG guidelines
- **Track** issues and remediation work in one place
- **Include real users** through lived-experience testing alongside automated checks

## What you'll find here

Our public repositories include open-source tooling, shared templates, and workflows we use to build and ship software. Where a repo is public, it's because we think others can use it too.

## Contributing

We welcome issues, suggestions, and pull requests on our public repositories.

1. Check the repo's README and open issues first.
2. Open an issue to discuss larger changes before starting.
3. Link your pull request to its issue (`Fixes #123`) and describe how you tested it.

## Accessibility feedback

If you find an accessibility barrier in any of our products or repositories, please open an issue or contact us. We treat these as high priority.
